# BASIC-NETWORK-SNIFFER
* A Python-based network packet sniffer developed using the Scapy library to capture and analyze live network traffic. This project monitors packets flowing through the system’s network interface and displays important information such as source IP address, destination IP address, protocol type, port numbers, and payload data.

The project helps in understanding how network communication works, how data is transmitted between devices, and how common protocols like TCP, UDP, and ICMP operate in real-time network traffic. * 

# TECHNOLOGIES USED
Python
Scapy Library
TCP/IP Networking Protocols
Packet Sniffing and Network Analysis Techniques
